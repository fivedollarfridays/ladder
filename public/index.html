Ladder

A tiered question deck that an agent can read, search, and build from — but cannot bluff past.

checking for WebMCP…

The deck is finite and it remembers. Every question is either available, reserved (asked on camera, not yet locked), or burned. An agent building a set has to work inside that, one question per difficulty rung, and it is told no when a rung has run dry rather than inventing something.

That constraint is the point. A generative model asked for five quiz questions will happily produce five it has already produced. This deck won't let it.

Tools exposed to the agent

deck_report — what remains, per rung, and which rungs are exhausted.
theme_search — deck coverage for a theme, and which rungs it can't cover.
build_set — a full set from a spec. Deterministic. Refuses to under-fill.
screen_candidates — would any of these repeat something already used?
